# 番茄钟悬浮样式 — 设计说明

## 交互

| 状态 | 外观 | 操作 |
|------|------|------|
|  idle（未计时） | 52px 圆形 🍅 按钮 | 点击 → 放大至 128px 并开始倒计时 |
|  running（专注/休息） | 128px，显示 MM:SS + 进度环 + 脉冲光晕 | 点击 → 重置并重新从 25 分钟开始 |
|  周期完成 | 自动缩回 52px | 侧边栏底部 +1 🍅 |

## 布局

```
┌──────────┬─────────────────────────────┐
│ Sidebar  │  [🍅] ← FloatingPomodoro     │
│          │                              │
│  Nav     │       Main Content           │
│          │                              │
│ ──────── │                              │
│ 🍅🍅🍅   │ ← PomodoroCount              │
│ User     │                              │
└──────────┴─────────────────────────────┘
```

- 桌面端：`fixed top-4`，left 随侧边栏展开/收起偏移（252px / 88px）
- 移动端：`left-4`，无侧边栏偏移

## Store 变更

- `start()` — 仅启动计时（`isRunning: true`）
- `restart()` — 重置为工作时长并立即开始
- 保留 `reset()` — 停止并回到工作时长（不自动开始）

## 动画

- Framer Motion `spring` 控制宽高缩放
- 专注中 `animate-pulse` + 红色光晕呼吸动画
- 新完成的 🍅 计数带 `scale` 入场动画
