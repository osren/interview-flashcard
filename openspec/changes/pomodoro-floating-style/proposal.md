# 番茄钟样式改进

## 背景

启动番茄钟后，原先仅在侧边栏区域闪烁倒计时，不够醒目，复习者缺乏专注感，无法沉浸。

## 目标

1. 将番茄钟移至主内容区左上角，作为悬浮按钮
2. 点击后图标放大并开始计时，计时中带有脉冲光晕
3. 一个番茄钟周期完成后自动缩回原始按钮尺寸
4. 左侧边栏底部显示已完成番茄计数
5. 支持点击重置并重新计时

## 范围

- `src/components/Pomodoro.tsx` — 拆分为 `FloatingPomodoro` + `PomodoroCount`
- `src/store/usePomodoroStore.ts` — 新增 `start` / `restart` action
- `src/components/Layout/AppShell.tsx` — 集成悬浮番茄钟与侧边栏计数

## 验收

- [ ] 左上角悬浮按钮可见，不遮挡侧边栏 Logo
- [ ] 点击开始后按钮放大并显示倒计时
- [ ] 专注周期结束后按钮缩回小尺寸
- [ ] 侧边栏底部出现 🍅 计数，每完成一个 +1
- [ ] 计时中点击或点「重置」可重新开始
