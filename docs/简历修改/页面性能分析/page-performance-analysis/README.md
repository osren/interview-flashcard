# 页面性能分析 Skill

## 简介

这是一个通用的页面性能分析工具，用于深度分析前端项目中任意页面的函数执行耗时情况，识别性能瓶颈，并提供优化建议。

## 功能特性

✅ **多技术栈支持**
- MPX/小程序
- Vue.js
- React
- 原生 JavaScript

✅ **全流程分析**
- 页面加载阶段
- 用户交互阶段
- 数据监听阶段

✅ **智能耗时评估**
- 网络请求耗时
- 数据处理耗时
- 渲染更新耗时

✅ **优化建议输出**
- 优先级分级（P0/P1/P2）
- 具体实施方案
- 预期收益评估

## 分析报告内容

### 1. 页面概述
- 基本信息（名称、路径、技术栈）
- 代码统计（行数、函数数、API数）
- 业务场景说明

### 2. 函数执行耗时排序
- 🔴 第一梯队：高耗时函数（>500ms）
- 🟡 第二梯队：中等耗时函数（200-500ms）
- 🟢 第三梯队：低耗时函数（<200ms）

### 3. 性能瓶颈分析
- 串行请求瀑布流
- Watch连锁触发
- 防抖节流问题
- 重复请求问题

### 4. 优化建议
- **P0级**：立即优化（关键问题，易实施）
- **P1级**：中期优化（效果显著，需成本）
- **P2级**：长期优化（架构层面，大改动）

### 5. 性能指标对比

|------|--------|--------|----------|
| FCP | - | < 1.8s | - |
| LCP | - | < 2.5s | - |
| TTI | - | < 3.8s | - |

## 分析维度详解

### 页面加载阶段
分析以下函数的执行耗时：
- 生命周期钩子（created、mounted、activated等）
- 初始化数据请求
- 组件初始化
- 路由守卫

### 用户交互阶段
分析以下函数的执行耗时：
- 事件处理器（onClick、onScroll等）
- 表单提交
- 导航跳转
- 弹窗操作

### 数据监听阶段
分析以下函数的执行耗时：
- Watch 监听器
- Computed 计算属性
- Store 订阅
- 事件总线监听

## 耗时评估标准

### 网络请求
| 类型 | 耗时范围 | 说明 |
|------|---------|------|
| 简单查询 | 100-300ms | 单表查询、少量数据 |
| 复杂查询 | 300-600ms | 多表关联、聚合计算 |
| 大数据量 | 600-1200ms | 分页、大量数据处理 |

### 数据处理
| 类型 | 耗时范围 | 说明 |
|------|---------|------|
| 简单赋值 | 1-10ms | 基础数据类型操作 |
| 数组遍历 | 10-50ms | map、filter、reduce等 |
| 复杂计算 | 50-200ms | 递归、嵌套循环等 |

### 渲染更新
| 类型 | 耗时范围 | 说明 |
|------|---------|------|
| 状态更新 | 5-20ms | 简单组件状态变化 |
| 列表渲染 | 20-100ms | v-for、map等列表更新 |
| 整页渲染 | 100-500ms | 页面级别重渲染 |

## 性能优化策略

### 网络请求优化
1. **并行化请求**：使用 Promise.all 合并无依赖请求
2. **请求去重**：相同参数的请求进行合并或缓存
3. **预加载**：提前加载可能需要的资源
4. **懒加载**：延迟加载非首屏内容

### 数据处理优化
1. **防抖节流**：合理设置防抖节流时间
2. **虚拟列表**：大数据列表使用虚拟滚动
3. **Web Worker**：复杂计算放入 Worker
4. **缓存策略**：使用内存或本地存储缓存

### 渲染优化
1. **组件懒加载**：延迟加载非关键组件
2. **shouldComponentUpdate**：减少不必要的渲染
3. **虚拟DOM优化**：合理使用 key
4. **CSS优化**：避免强制同步布局

## 注意事项

1. **业务场景理解**
   - 了解页面的核心业务逻辑
   - 识别关键用户路径
   - 考虑不同入口的影响

2. **技术栈适配**
   - Vue: 关注生命周期、watch、computed
   - React: 关注 hooks、effect、memo
   - 小程序: 关注页面生命周期、setData

3. **性能测量**
   - 使用 Chrome DevTools 进行真实测量
   - 对比优化前后的性能指标
   - 持续监控性能变化
