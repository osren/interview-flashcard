## 模块说明

与暑期实习 PDF 简历一致，条目格式 `**简述名称**：具体内容`；01～04 为标准六条，05 压缩为三行。

### 实习经历
整合自 `滴滴实习工作总结.md`、`滴滴实习描述.md`、`滴滴实习经历简历版.md`  
时间口径：**2026.01 — 2026.07** · 岗位：前端开发实习生 · 部门：商旅体验  
写法：**C 端 + B 端双端覆盖**，数量用总交付量（如 **20+** 项 / **15 次 release**），不拆分甲子/机火各自计数

### 实习产出（并列两项）
1. **性能监控与体验优化** — PerfMonitor 真测轨 + page-performance-analysis Skill 分析轨  
2. **商旅 AI 智能监控降噪** — error-triage 告警 LLM 判定引擎

周期：**2025.12 — 2026.09** · 角色：独立设计与实现 · 项目：**InterviewFlash**（不含 GResume）

## 诚实边界（全版本通用）

- 机酒火多品类需求只写本人负责的 **机票侧 / 火车票侧**
- 甲子侧多数为前端协助，ownership 用「独立落地 / 参与 / 协助」区分
- AI 监控：火车 Domain 已接入；机酒 url 已摘、Domain 待 onboard；派发通道当前为日志占位
- 性能数字（LCP ↓17%、卡顿 ↓27%）来自团队口径，面试前请与个人参与度对齐
- InterviewFlash 为个人项目，勿写虚假 DAU / 付费数据；Algorithms 模块当前未实现勿写

## 导出 PDF（秋招简历 v2 · 推荐）

**v2 结构**：借鉴许科简历写法 — 实习/项目均按 **项目描述 → 技术栈 → 主要工作** 三段式；模块顺序为 **教育 → 实习 → 项目 → 技能**。

| 版本 | Markdown | HTML 导出 |
|------|----------|-----------|

| AI 强化版 | `秋招简历v2-AI强化版.md` | `秋招简历v2-AI强化版.html` |

**导出步骤**：Chrome 打开对应 `.html` → 打印 → 另存为 PDF（A4，边距默认）

## 导出 PDF（秋招简历 v1 · 旧版）

优化后内容见 `秋招简历v1-排版稿.md` / `秋招简历v1.html`，模块顺序：**教育 → 技能 → 实习 → 产出 → 项目**。

**方式一（推荐）**：用 Chrome 打开 `秋招简历v1.html` → 打印 → 另存为 PDF（A4，边距默认）

**方式二**：将排版稿正文粘贴进 `秋招简历v1.docx`（保留证件照与 Word 样式）→ 导出 PDF

**方式三**：释放磁盘空间后，在目录下执行 `npm install puppeteer && node generate-pdf.js`
