## 实习产出

### 性能监控与体验优化

**商旅页性能监控与体验优化** | PerfMonitor / Omega / Web Vitals | 实习产出

- 监控体系：搭建跨页链路、Web Vitals 与关键接口耗时的统一监控，H5/星河双端统一上报
- 体验收益：列表首屏 LCP **1400→1160ms（↓17%）**；星河底部菜单切换卡顿约 **↓27%**
- 方法论：沉淀性能分析 Agent Skill，与监控指标形成「定位 → 改造 → 验收」闭环
- 技术实现：PerfMonitor 覆盖跨页链路与 Web Vitals，环境抽象兼容 H5/星河；列表优化接口返回与缓存直渲双路径，剥离非关键接口拖长 LCP 的路径

### 商旅 AI 智能监控降噪

**商旅 AI 告警智能降噪（error-triage）** | Node.js / LLM | 实习产出

- 业务问题：机酒火接口告警噪音高，真故障易被淹没，需在派发前智能判定
- 核心能力：每条告警 LLM 判定，输出是否上报、P0–P3、错误类型与中文依据
- 工程保障：可插拔 Domain 架构 + Skills 接入 + Eval 漏报优先评测；异常保守上报，火车 Domain 已接入
- 技术实现：Node.js + LLM Gateway 实现单条告警判定管线；Domain 承载路由表与分类 Prompt，Skills 自动化接口发现与 Domain 生成
