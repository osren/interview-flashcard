### 商旅 AI 智能监控降噪

**商旅接口错误告警智能降噪（error-triage）** | Node.js / LLM / Prompt 工程 | 实习产出

- 业务背景：机酒火接口告警噪音高、真故障易被淹没，需在派发值班前完成智能降噪判定
- 方案落地：基于 LLM 实现告警智能判定（是否上报、严重等级、错误类型与依据），引擎与业务 Domain 解耦，支持多团队接入
- 质量保障：配套 Agent Skills 降低接入成本，Eval 以漏报率为首要指标；异常场景保守上报，火车 Domain 已接入
- 技术实现：Node.js 告警引擎（HTTP/Kafka 双入口 → 路由 → Prompt 编排 → LLM 网关）；业务知识配置化下沉 Domain，配套 discover/onboard Skills 与 Eval 回归
