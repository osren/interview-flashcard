## 📋 一、实际已完成的优化（代码级验证）

### 优化 1: 首页延迟加载 + 缓存统计

**文件**: `src/pages/Home.tsx`

**优化前代码**:
```typescript
useEffect(() => {
  let cancelled = false;
  // ❌ 立即加载全量卡片（604 张）
  void Promise.all([loadAllCoreCards(), loadAllProjectCards()]).then(([core, projects]) => {
    if (cancelled) return;
    setLoadedCardIds([...core, ...projects, ...mpxCards].map((c) => c.id));
  });
  return () => { cancelled = true; };
}, []);

// ❌ 每次都遍历全量卡片计算进度
const totalRemembered = allCardIds.filter((id) =>
  isRemembered(resolveCardStatus(id, cardStatuses))
).length;
```

**优化后代码**:
```typescript
useEffect(() => {
  let cancelled = false;
  // ✅ 延迟 1 秒加载（用户可能已跳转）
  const timer = setTimeout(() => {
    setIsLoadingFull(true);
    void Promise.all([loadAllCoreCards(), loadAllProjectCards()]).then(([core, projects]) => {
      if (cancelled) return;
      setLoadedCardIds([...core, ...projects, ...mpxCards].map((c) => c.id));
      setIsLoadingFull(false);
    });
  }, 1000);
  
  return () => {
    cancelled = true;
    clearTimeout(timer);
  };
}, []);

// ✅ 使用 localStorage 缓存快速计算（只遍历已标记的卡片）
const cachedRemembered = useMemo(() => {
  return Object.keys(cardStatuses).filter((id) =>
    isRemembered(cardStatuses[id])
  ).length;
}, [cardStatuses]);

const totalRemembered = loadedCardIds.length > 0 
  ? allCardIds.filter((id) => isRemembered(resolveCardStatus(id, cardStatuses))).length
  : cachedRemembered;
```

**优化原理**:
1. **延迟加载**: 首屏不需要完整数据，延迟 1 秒加载（用户留存率考虑）
2. **缓存计算**: localStorage 中只存已标记的卡片，遍历速度远快于全量 604 张
3. **渐进增强**: 先显示估算值，完整数据加载后更新精确值

**理论分析**:
- 优化前: 需要加载 604 张卡片，每张约 0.5-1ms，总计 **300-600ms 阻塞**
- 优化后: 只遍历 localStorage 的 key（通常 < 50 条），总计 **< 5ms**
- 改善: **首屏可立即交互，加载延迟到后台**
