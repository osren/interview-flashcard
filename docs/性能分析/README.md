### 5.2 关键优化策略

#### 策略 1: 延迟加载模式
```typescript
setTimeout(() => {
  void loadNonCriticalData().then(...)
}, 1000);
```
**适用场景**: 首屏加载、非关键数据

---

#### 策略 2: 缓存优先策略
```typescript
const cachedData = useMemo(() => {
  return Object.keys(storage).filter(predicate);
}, [storage]);
```
**适用场景**: 频繁计算、重复查询

---

#### 策略 3: 虚拟化渲染
```typescript
<FixedSizeList itemCount={1000} itemSize={68}>
  {({ index, style }) => <Item index={index} style={style} />}
</FixedSizeList>
```
**适用场景**: 大列表、SVG 图表

---

#### 策略 4: Web Worker 异步处理
```typescript
const worker = new Worker('task.worker.js');
worker.postMessage({ data });
worker.onmessage = (e) => { setResult(e.data); };
```
**适用场景**: PDF 提取、Diff 计算

---

#### 策略 5: 乐观更新
```typescript
// 立即更新 UI
updateLocal(id, data);

// 后台同步
setTimeout(() => syncToCloud(id, data), 1500);
```
**适用场景**: 云端同步、网络请求
