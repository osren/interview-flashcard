# 自我介绍发言稿（精简版）

---

面试官您好，我叫谭成，重庆邮电大学计算机科学与技术专业研二在读，本科是西南石油大学数据科学与大数据技术。今天应聘的是前端开发工程师岗位。下面我从实习经历、个人项目和技能积累三个方面做个介绍。

先说实习。我目前在滴滴企业级事业部商旅体验团队做前端开发实习生，主要参与C端预订链路和B端配置中台的交付。团队有一套AI Coding Spec的约束体系，业务仓接入了Rules、Agent约束和Skills，让大模型在组内规范下协作开发。我负责过机票、火车票预订端的需求实现，以及后台配置模块的联调上线。其中我印象比较深的是机票政策模块的重构：原来是一堆jQuery加硬编码，扩展性很差，我把它改成JSON Schema配置驱动的动态表单，新增政策类型只需要改配置，不用动组件代码。另外我做了弱网优化，用@loadable/component做路由分割和预加载，FCP从3.2秒降到1.8秒，首屏JS体积减少了45%。在这套规范约束下，我完成了20多项C端和B端交付，经历了15次稳定发版。我还参与了商旅AI告警降噪服务，核心思路是判定交给模型、工程只做路由编排，我负责火车票Domain的路由表和Prompt配置，以及评测链路搭建，把业务正常的拒绝和展示类噪音挡在IM和工单之前。

再说个人项目。我独立开发了一个叫InterviewFlash的秋招面试备战平台，技术栈是React 18、TypeScript、Vite、Zustand加Supabase。它把闪卡刷题、AI讲解追问、投递追踪、JD解析、简历优化和面经复盘打通成一个闭环。AI讲解这块，我基于闪卡上下文构建Explain和Follow-up的Prompt，注入项目案例和候选人背景，用SSE流式输出，会话本地缓存避免重复扣费。LLM工程化方面，我用Edge Function统一代理模型，做JWT鉴权和日额度原子扣减，API Key不暴露在前端。性能上做了路由和章节懒加载，配合Vite拆包，Campus Tab用keep-alive优化切换体验。另一个项目GResume是智能简历平台，走离线优先路线，用IndexedDB加Automerge CRDT做本地编辑，再和Supabase同步，接入了DeepSeek做ATS评分和流式响应。

最后说下技能。我熟练掌握React和TypeScript，熟悉Vue，也具备小程序和H5多端经验，常用Ant Design和Tailwind，状态管理用过Redux和Zustand。AI应用方面，我熟悉Prompt工程、结构化输出、Eval评测闭环，以及SSE流式交互和AI Coding协作开发。工程化上熟悉Vite、Webpack、Git，了解Node.js和Supabase Edge Functions。

我的优势可以概括为三点：一是有大厂企业级业务的真实交付经验，理解规范和发版流程；二是有AI应用落地的工程能力，不只是调API，而是考虑鉴权、额度、评测和成本；三是有独立做完整产品的习惯，从产品设计到性能优化都能自己扛。我希望能在贵司的前端岗位上，把这些经验用在真实的业务场景里，也持续补齐自己的短板。以上是我的自我介绍，谢谢。
