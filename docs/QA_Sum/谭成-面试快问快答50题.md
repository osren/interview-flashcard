## 一、简历 & 项目（18 题）

**1. 用 30 秒介绍你自己。**  
研三前端方向；滴滴商旅实习 7 个月（性能监控 + AI 告警降噪）；个人项目 InterviewFlash（秋招刷题+AI）和 GResume（简历+协作）。

**2. 为什么数本跨考前端？**  
本科做数据分析发现「算得准」不如「用得爽」；更喜欢把复杂信息做成好用界面，数据思维帮助看指标和做决策。

**3. 滴滴商旅性能项目解决什么问题？**  
列表页慢（LCP 约 1.4s）、底部菜单卡；缺函数级/接口级数据，定位靠经验。

**4. perf-monitor 做了什么？**  
封装 mark/measure/report；H5 和小程序用 Adapter 统一上报；监控跨页链路、LCP/FCP、关键接口耗时。

**5. 列表页 LCP 怎么从 1400 降到 1160？**  
① 切日期缓存命中直接渲染，不重复请求；② 接口/渲染/绘制分开统计后精准优化；③ 隐私弹窗等非首屏逻辑 defer 延后。

**6. cacheHit 状态机解决什么？**  
有缓存还发请求导致白等；状态明确：命中缓存 → 跳过请求 → 直接渲染；避免竞态用请求序号/取消旧请求。

**7. H5 和小程序性能怎么统一？**  
Adapter 层统一字段名、单位、环境标签；缺指标用业务等价点代替；分端看优化趋势，不硬比绝对值。

**8. 星河底部菜单卡顿怎么优化？**  
不是大数据排序慢，是每次切换都重排+重渲染；useMemo 缓存排序结果，数据不变不重算。

**9. Lighthouse 和线上监控区别？**  
Lighthouse 是实验室数据；我们是真实用户环境打点，能对应到具体接口和业务逻辑（如切日期缓存）。

**10. AI 告警降噪解决什么问题？**  
机酒火告警太多，很多是「没票、已退改」等业务正常结果；真故障被淹没，值班容易漏看。

**11. 为什么用 LLM 而不是纯规则？**  
业务语义复杂，硬规则容易误杀；改 Prompt 比改代码快；工程侧用兜底和评测保证不漏报。

**12. business_reject 是什么？**  
「看起来像报错，其实是正常业务」的清单（如无票）；写进 Prompt，但要防误杀，信息不全默认上报。

**13. safeFallback 干什么？**  
模型超时/解析失败 → 仍上报，保守 P2；**绝不静默丢弃告警**。

**14. 为什么 FN（漏报率）是核心指标？**  
漏真故障可能出事故；多报噪音顶多多看一眼。样本里噪音占多数，不能只看准确率。

**15. InterviewFlash 是什么？**  
秋招一站式：闪卡刷题 + AI 讲解追问 + 投递进度看板 + 按 JD 改简历；离线可用，登录云同步。

**16. InterviewFlash 的 AI 怎么工程化？**  
API Key 只在 Edge Function；JWT 鉴权；日额度 RPC 原子扣减；SSE 流式输出；会话缓存省重复扣费。

**17. GResume 和 InterviewFlash 区别？**  
Flash 偏面试备战（刷题+投递）；GResume 偏写简历（富文本+模板+协作+PDF）。两个独立项目。

**18. GResume 协作怎么不冲突？**  
结构化字段用 Automerge CRDT 自动合并；富文本用 Yjs 字符级合并；离线改完联网自动 sync。

## 二、前端八股（16 题）

**19. 从输入 URL 到页面显示发生了什么？**  
DNS → TCP/TLS → 请求 HTML → 解析 DOM/CSSOM → 渲染树 → 布局 → 绘制；JS 可能阻塞解析，CSS 阻塞渲染。

**20. 重排（reflow）和重绘（repaint）区别？**  
重排：几何变化，可能触发后续布局；重绘：外观变化不一定改布局。重排代价通常更大。

**21. LCP、FCP、CLS 各是什么？**  
FCP：首次有内容；LCP：最大主要内容出现；CLS：布局抖动累计。Good：LCP≤2.5s，CLS≤0.1。

**22. 宏任务和微任务执行顺序？**  
执行栈空 → 清空微任务队列（Promise.then）→ 取一个宏任务（setTimeout）→ 循环。微任务优先于下一个宏任务。

**23. Promise、async/await 关系？**  
async 函数返回 Promise；await 暂停等待 Promise 结果。错误用 try/catch 或 .catch。

**24. 闭包是什么？有什么用？**  
函数记住定义时的词法环境。用途：私有变量、柯里化、防抖节流里保存 timer。

**25. 防抖和节流区别？**  
防抖：停止触发后才执行（搜索框）；节流：固定间隔最多执行一次（滚动监听）。

**26. 事件循环中 setTimeout(0) 是立刻执行吗？**  
不是，是宏任务，等当前同步代码和微任务跑完才执行。

**27. React 虚拟 DOM 为什么快？**  
不是绝对快，是 **批量更新 + Diff 最小化真实 DOM 操作**；跨平台统一抽象。

**28. useEffect 和 useLayoutEffect 区别？**  
useLayoutEffect 在浏览器绘制前同步执行，适合读布局防闪烁；useEffect 异步，不阻塞绘制。

**29. useMemo 和 useCallback 区别？**  
useMemo 缓存 **计算结果**；useCallback 缓存 **函数引用**。都靠依赖数组决定何时重算。

**30. React 18 并发特性了解吗？**  
自动批处理、Transitions（低优先级更新）、Suspense 增强。核心：可中断渲染，提升响应性。

**31. 跨域是什么？常见解决方案？**  
浏览器同源策略限制不同源请求。CORS、代理、JSONP（老）、postMessage。

**32. 浏览器缓存策略？**  
强缓存（Cache-Control/Expires）不发请求；协商缓存（ETag/Last-Modified）问服务器是否过期。

**33. 前端性能优化你从哪几层讲？**  
加载（拆包、懒加载、CDN）、渲染（减少重排、虚拟列表）、网络（缓存、合并请求）、运行时（Web Worker、防抖节流）。

**34. TypeScript 里 type 和 interface 区别？**  
都能描述类型；interface 可声明合并、更适合对象扩展；type 更灵活（联合、交叉、映射）。

## 三、AI 八股（16 题）

**35. 大模型推理时 temperature 是什么？**  
控制随机性。0 更确定、适合分类判定；高则更发散、适合创意。生产判定类常设 0。

**36. Prompt 和 System Prompt 区别？**  
System：全局规则、角色、安全边界；User：本次具体问题。System 优先级应高于用户输入。

**37. 什么是 Prompt 注入？怎么防？**  
用户输入试图覆盖系统指令。防护：指令与数据分离、输出 schema 校验、权限在后端、限流。

**38. RAG 是什么？解决什么问题？**  
检索增强生成：先查知识库，再让模型基于检索结果回答。解决模型 **不知道私有/最新知识** 和幻觉。

**39. RAG 和微调（Fine-tuning）怎么选？**  
RAG：知识常更新、要可溯源、成本低；微调：固定风格/格式、领域深度适配。常组合使用。

**40. 什么是幻觉（Hallucination）？怎么缓解？**  
模型编造不存在的事实。缓解：RAG、结构化输出、温度调低、人工审核、评测集回归。

**41. Token 是什么？为什么关心 Token 成本？**  
模型处理文本的单位（约 1 汉字≈1～2 token）。按 token 计费；上下文越长越贵越慢。

**42. 上下文窗口（Context Window）是什么？**  
模型一次能看的最大 token 数。超长要截断、摘要或 RAG 只塞相关片段。

**43. SSE 和 WebSocket 区别？AI 流式常用哪个？**  
SSE：服务端单向推、HTTP、自动重连，适合 **AI 逐字输出**；WebSocket 双向，适合聊天室、协作。

**44. 结构化输出（JSON Mode）为什么重要？**  
下游要解析执行（如告警判定 should_report）；减少自由文本解析失败；配合 schema 校验。

**45. Agent 和普通 Chat 区别？**  
Agent：能 **规划多步、调工具、循环执行** 直到完成任务；Chat 多为单轮/多轮对话无工具编排。

**46. Function Calling / Tool Use 是什么？**  
模型输出「要调哪个函数+参数」，由程序执行后把结果再喂给模型。是 Agent 落地的基础。

**47. 模型评测为什么不能用单一准确率？**  
样本不平衡时「全不报」准确率也高。要看召回、漏报、F1，结合业务代价选指标（如告警看 FN）。

**48. 什么是 Embedding？**  
把文本变成向量，语义相近的文本向量距离近。用于 RAG 检索、聚类、相似度搜索。

**49. 向量数据库解决什么问题？**  
高效存储和检索高维向量（百万级相似度搜索），RAG 里查「和问题最相关的文档块」。

**50. 你做过的 AI 项目里，工程上最重要的是什么？**  
**别只调 Prompt**：要有鉴权、额度、兜底、评测、流式体验、密钥不出前端。AI 负责判断，工程负责 **可靠交付**。
